# 测试策略与已知限制（Windows 11 原生部署版）

本项目包含 JUnit 单元测试、独立 API 冒烟测试脚本、前端结构检查与 335 个补充测试场景。**335 条是待执行场景，而不是 335 项已通过结果**。

- 首次运行 `start-his.bat` 时自动执行 `npm run build` 和 `mvn clean verify`。任何编译或 JUnit 失败都应导致一键部署失败，不能伪报成功。
- 如需单独执行 JUnit，在新的 PowerShell 中进入 `backend` 目录并执行 `mvn -B clean verify`；JaCoCo 报告位置 `backend/target/site/jacoco/index.html`。
- 页面静态结构检查：`python tests/check_ui_structure.py`（需额外安装 Python，此检查不是浏览器交互回归）。
- 跨角色 API 冒烟测试：`python tests/api_smoke.py --url http://127.0.0.1:8088 --admin <密码> --demo <密码>`（会写入**虚构**业务数据，须使用专用演示数据库）。
- 浏览器 E2E、弱网、并发与跨端兼容测试尚未完成，不得误称生产可用。

## 发布时已验证/未验证

源码静态检查及文件打包检查可以在交付环境执行。但当前环境**无法运行 Windows 11 进程、下载 Maven/npm 依赖或启动 MySQL**，所以本机安装、真实登录闭环、数据库迁移、首次下载及启动时的实际行为均未能在目标平台执行验证。**交付状态是 Windows 原生部署候选版**。在 Windows11 上运行后应保存构建日志、健康检查和测试报告，再确定是否达到项目验收条件。
