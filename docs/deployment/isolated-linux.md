# Linux 独立部署与运维

本项目支持将 Java、MySQL、应用和数据放入独立目录运行，不要求替换系统 Java/MySQL 或修改已有站点配置。

## 部署约定

- HTTP 与数据库分别使用新的空闲端口，数据库只监听 127.0.0.1。
- Java 使用 Temurin 21 便携 JRE，下载时按 Adoptium 官方 SHA256 校验。
- MySQL 使用官方便携归档；本次使用的 8.4.4 归档按官方 MD5 校验，并另记录 SHA256。
- 缺少客户端兼容库时，将 Ubuntu 官方仓库包解压到应用目录，不修改系统库。
- 所有配置和数据均在部署目录内生成，不从开发电脑上传数据库、登录会话或私有配置。
- 若用 systemd 管理，仅新增本项目唯一命名的服务文件和链接，不覆盖既有服务。

## 配置与数据

在服务器生成全新随机数据库密码和 64 位十六进制数据加密密钥。应用配置保存在私有 EnvironmentFile 中，权限限制为部署用户可读。登录密码由实例配置决定，仓库不保存实例凭据。

仿真资料在新数据库中生成，与开发电脑数据库独立。备份时需同时保留数据库与匹配的加密密钥。

## 运维示例

以下服务名是示例，应替换为实际部署新增的名称：

```sh
systemctl --user status his-db his-web
systemctl --user restart his-web
journalctl --user -u his-web -n 100 --no-pager
systemctl --user stop his-web his-db
systemctl --user start his-web
```

用户服务开机运行需要用户管理器在退出后继续运行；不得为此覆盖已有站点或服务文件。

## 验证边界

已通过远端实例的首页 HTTP 200、健康接口 UP、七类账号登录、越权接口拒绝、24 份现场生成的合成患者资料和多患者业务记录核验。自动浏览器工具连续超时，未取得远端页面截图；这些接口验证不代表完整视觉验收。
